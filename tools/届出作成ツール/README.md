# 届出作成ツール v1.1（実装物）

入退職時の届出チェックリストと、社保・雇保の届書データを作るExcelツール。
設計は `docs/20261029_計画書_届出スクリプト化◎_v1.0.md`、仕様は同 `実装手順書`（第15章が最新）、担当者向けの使い方は `docs/20261029_運用手順書_届出作成ツール_v1.0.md`（中身はv1.1）。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `届出作成ツール_v1.1.xlsx` | マクロなしのブック（ダミーデータ入り）。Windowsでマクロを取り込んで `.xlsm` にする |
| `vba/modExport.bas` | VBEで取り込むファイル（Shift_JIS・CRLF）。**直接編集しない** |
| `vba/modExport_utf8.bas` | マクロの原本（UTF-8。GitHubで読める）。直すのはこちら |
| `build_tool.py` | ブックと `modExport.bas` を作り直すスクリプト |
| `test/lo_test.py` | LibreOfficeでの自動試験18項目（Windows Excelでの最終確認の前の予備試験） |

v1.0 からの変更：社保取得・社保喪失のCSVを、年金機構の電子媒体届書作成仕様書（令和8年10月 第17.0版）の形式にした。設定シートの項目が変わった（事業所整理記号 → 都道府県コード・郡市区符号・事業所記号など）ので、v1.0 のブックは使い続けず、v1.1 に入れ替える。

## Windowsで完成させる手順（初回のみ・約10分）

v1.0 を取り込み済みの場合も、同じ手順で v1.1 を作り直す（v1.0 には実データを入れていないので、入れ替えて問題ない）。

1. `届出作成ツール_v1.1.xlsx` と `modExport.bas` を自分のPCの作業フォルダにコピーする。
2. Excelで `届出作成ツール_v1.1.xlsx` を開き、`Alt+F11` でVBE（マクロの編集画面）を開く。
3. VBEのメニュー「ファイル」→「ファイルのインポート」で `modExport.bas` を選ぶ。左の一覧に「標準モジュール → modExport」が出ればよい。
4. VBEのメニュー「デバッグ」→「VBAProject のコンパイル」を押す。何も表示されなければ成功。
5. VBEを閉じ、Excelで `Alt+F8` →「SetupButtons」→「実行」。出力シートに［チェック］［CSV出力］、各台帳に［台帳をクリア］のボタンが付く。
6. 「名前を付けて保存」→ ファイルの種類「Excel マクロ有効ブック (*.xlsm)」→ `届出作成ツール_v1.1.xlsm` で保存する。
7. 動作確認：出力シートで「社保取得」を選び［チェック］→［CSV出力］。ダミー3名が出力され、`出力\社保取得_日付_時刻\SHFD0006.CSV` ができる。

## 仕様の確定（社保取得・社保喪失）

レイアウトは仕様書第17.0版から作ってある。**届書作成プログラムの「仕様チェック」でエラー0件になるまでは「確定＝未」**（設定シートの届種別一覧）。

1. 設定シートの黄色い値を実際の値に直す：都道府県コード（長野県は37）、郡市区符号、事業所記号（半角カナ）、事業所番号、事業所の郵便番号・所在地・電話、法人名、事業主氏名、媒体通番（前回の続き）。事業所記号は納入告知書等の事業所整理記号を、上2桁（郡市区符号）とそれ以外（事業所記号）に分ける。
2. ダミー1名で社保取得を出力する。
3. 届書作成プログラム（Ver.34.00）の起動メニュー「仕様チェック 社会保険(S)」を開き、`SHFD0006.CSV` のあるフォルダを指定してチェックする。
4. エラーが出たら、メッセージの項目を「レイアウト定義」シートの該当行と仕様書で突き合わせて直す（マクロは直さない）。
5. エラー0件になったら、社保喪失も同じ手順で確認し、届種別一覧の「確定」を「済」にして、変更履歴に記録する。

## 分かっていること・未確認のこと

- マイナンバーは扱わない（個人番号欄は空欄で出力）。個人番号がないため、基礎年金番号（上4桁・下6桁）と住所が届書に必要。基礎年金番号が空だと警告が出る。
- 漢字氏名（全角12文字）・漢字住所（37文字）は仕様で省略できる欄。使えない文字や超過は自動で省略して警告する。カナは半角カナ。
- 取得届と喪失届は別々のファイル（別フォルダの `SHFD0006.CSV`）。仕様上は1ファイルに混在もできるが、運用を簡単にするため分けている。
- 雇用保険は転記一覧のまま。届書作成プログラムの「仕様チェック 雇用保険(E)」の仕様書（公共職業安定所向け `shutoku.csv`）を入手したらCSV化を検討する。
- 届書作成プログラムには、事業所が持つ被保険者情報のCSVを取り込む機能（データを取り込む）もある。操作説明書（詳細版）の第4章・別添3・別添4に項目がある。現状は仕様書のレコード形式で出力する方式にしている。

## 作り直し・試験（開発者向け）

```bash
python3 "tools/届出作成ツール/build_tool.py"
```

```bash
python3 "tools/届出作成ツール/test/lo_test.py" /tmp/届出試験
```

- `build_tool.py` はダミーデータ入りの初期状態を作る。**運用開始後のブック（実値入り）を上書きしないこと。** 運用後の修正はブック側で行い、マクロを直したときは原本（UTF-8）を直して `build_tool.py` で `modExport.bas` を作り、VBEで古いモジュールを削除してから取り込み直す。
- LibreOfficeの試験では Shift_JIS 判定（機種依存文字の警告）とUTF-8以外の書き出しは確認できない。Windows Excelで確認する（テスト記録の「Windowsで確認する項目」）。
- 試験用フラグ：`gTestMode`（メッセージボックスを出さない）、`gSkipSjis`（Shift_JIS判定を省く）。運用では使わない。
