## 2. 手順

### 手順1 変更指示書を反映する

`docs/20261105_変更指示書_届出作成ツール.md` のとおりに直して上書き保存する。

1. 「レイアウト定義」シート：7・16・29・38・52・87行目のJ列（変換）に `半角カナ` と入れる。
2. 「設定」シート：F31・F32（社保取得・社保喪失の「確定」）を `済` にする。
3. 「変更履歴」シートに2行書く（変更指示書の第2章・第5章の例文）。

### 手順2 設定シートに実際の値を入れる

黄色の欄を、手元の書類を見て入れる。都道府県コードは `37`（長野県）のまま。

| 項目 | どこを見るか | 入れ方の例 |
| --- | --- | --- |
| 郡市区符号 | 「納入告知書 納付書・領収証書」の事業所整理記号の上2桁 | 整理記号が「01－ケイト」なら `01`。**初期値の `00` のままだと、仕様チェックで「提出元ID不正」になる。`00` と `99` は使えない** |
| 事業所記号 | 同上 | 同じく `ｹｲﾄ`（全角でも自動で半角になる） |
| 事業所番号 | 同上の事業所番号 | `123`（数字だけ） |
| 事業所_郵便番号 | 年金事務所に届けている所在地 | `390-0000` |
| 事業所_所在地 | 同上 | 都道府県名から、全角37文字以内 |
| 法人名 | 同上の事業所名称 | 全角25文字以内 |
| 事業主氏名 | 理事長の氏名 | 姓と名の間に全角スペース1つ。役職は入れない |
| 事業所_電話 | 年金事務所に届けている電話番号 | `0263-00-0000`（ハイフン2つ） |
| 雇保事業所番号 | 雇用保険の適用事業所番号（ハローワークの書類） | `0000-000000-0` |

入れ終わったら、出力シートで「社保取得」を選び［チェック］を押す。設定に関するエラーが出たら、その項目を直す。

### 手順3 実際の値で仕様チェックをもう1回かける

**手順2を済ませてから行う。** 設定シートの郡市区符号が初期値の `00` のままだと、仕様チェックで「媒体管理・項番2・提出元ID不正」になる（2026-11-05 に実際に発生）。

1. 台帳はダミー職員のまま、「社保取得」で［CSV出力］を押す。
2. 届書作成プログラムの「仕様チェック 社会保険(S)」で、できたフォルダを指定してチェックする（提出先は年金事務所、提出方法は電子申請）。
3. エラー0件なら次へ。エラーが出たら、画面の写真を Claude に貼る。
4. **このCSVは提出しない**（中身はダミー職員）。

### 手順4 文字の確認（W11・W12）

1. 手順3の `SHFD0006.CSV` を右クリック →「プログラムから開く」→「メモ帳」。半角カナ（ﾔﾏﾀﾞ ﾀﾛｳ など）が文字化けしていなければよい（W11）。
2. 入職台帳のダミー1人の氏名を「髙田 太郎」に変えて［チェック］を押す。「機種依存文字」または「漢字氏名を省略」の警告が出ればよい（W12）。確認したら元の氏名に戻す。

### 手順5 媒体通番を戻し、ダミーを消す

1. 設定シートの「媒体通番」を、本番の1回目に使う番号にする。電子媒体・電子申請で届書を出したことがなければ `001`。出したことがあれば、前回の続きの番号。試しに出力するたびに1つ進むので、ここで必ず直す。
2. 「入職台帳」「退職台帳」で［台帳をクリア］を押す。
3. 「内容確認」シートの中身を消す。「ログ」シートの試験の行は、消しても残してもよい。
4. 上書き保存する。
5. `出力` フォルダの中のダミーのCSVフォルダは、共有サーバへ持っていかない。

### 手順6 共有サーバへ移す（管理者が行う）

**移す前に確認すること（2分）**：設定シートの「確定」（F31・F32）が `済`、媒体通番が本番の番号、台帳とダミー出力が空であること。運用手順書（Word）の第9章「問い合わせ先」の `（担当者名を記入）` を、実際の担当者名に直しておく。

1. 共有サーバの人事フォルダに、アクセスできる人を絞った `届出作成ツール` フォルダを作る。
2. `届出作成ツール_v1.1.xlsm` と運用手順書（Word）を置く。`出力` フォルダはツールが自動で作る。
3. 担当者のPCごとに、Excelの「信頼できる場所」にこのフォルダを登録する（運用手順書 第2章）。
4. ブックは、ドライブ文字（例 `Z:\`）か `\\サーバ名\…` の場所から開く。OneDrive や SharePoint のURLから開くと出力フォルダが作れない。
5. 今のフォルダに残ったxlsmは、本番では使わない（控えとして残すか、消すかを決める）。

### 手順7 担当者への説明と1か月の運用

1. 担当者に運用手順書（第3章 採用、第4章 退職、第7章 やってはいけないこと）で説明する。
2. 実案件で1か月使ってもらう。
3. 1か月後、ヒアリングシートの「年間件数」「1件あたり作業時間」を書き直してもらう。導入前後の比較に使う。
