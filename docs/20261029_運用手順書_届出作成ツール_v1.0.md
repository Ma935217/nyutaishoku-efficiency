# 届出作成ツール 運用手順書 v1.0_20261029（届出担当者向け）

> **名称**：届出作成ツール 運用手順書
> **版数・状態**：v1.0_20261029／🧪未検証（Windows Excelでの初回確認前）
> **対象**：人事部の届出担当者
> **ツールの置き場所**：共有サーバの人事フォルダ（管理者が決める。本書では「ツールフォルダ」と呼ぶ）
> **安全ルール**：共通ルール v2.1（Notion）第3条・第4条。本書固有の禁止事項は第7章

---

## 1. このツールでできること

| 機能 | 内容 | 使うシート |
| --- | --- | --- |
| A. 届出チェックリスト | 1名分の条件を選ぶと、必要な届出・提出先・期限日の一覧が出る。印刷して進捗管理に使う | チェックリスト |
| B. 届書データ作成 | 入退職管理マスタの行を貼り付けると、社保の取得届・喪失届のCSV、雇保の取得届・喪失届の転記一覧ができる | 入職台帳・退職台帳・出力・内容確認 |

- 社保のCSVは、年金機構の「届書作成プログラム」に読み込んで電子申請に使う。
- 雇保は、内容確認シートの転記一覧を見ながらe-Gov等に入力する。
- 電子申請の「送信」と、マイナンバーの入力は担当者が行う。ツールはマイナンバーを扱わない。

## 2. 初回だけ行うこと

1. 管理者から、ツールフォルダの場所と `届出作成ツール_v1.0.xlsm` を教えてもらう。
2. Excelで「ファイル」→「オプション」→「トラストセンター」→「トラストセンターの設定」→「信頼できる場所」を開く。
3. 「ネットワーク上の信頼できる場所を許可する」にチェックを入れ、「新しい場所の追加」でツールフォルダを登録する。
4. ツールを開き、出力シートにボタンが表示され、押して反応すれば準備完了。
5. 設定できない場合は、ツールを自分のPCにコピーして使い、出力されたCSVだけをツールフォルダの「出力」フォルダに保存する。

## 3. 採用者の届出（毎月・入職のたび）

1. 入退職管理マスタを開き、入職DBで今回の対象者の行を選んでコピーする（`Ctrl+C`）。
2. ツールの「入職台帳」を開き、「DB貼り付け欄」の5行目以降の空いている行の先頭（「No.」の列）を選ぶ。
3. **値で貼り付ける**：`Ctrl+Alt+V` →「値」→ OK。普通の貼り付けは数式やリンクが混ざるので使わない。
4. 左側の「職員番号（表示）」「氏名（表示）」に名前が出たことを確かめる。
5. 黄色の「追加入力」列を埋める。届書に必要でマスタにない項目（性別・報酬月額・被扶養者・雇用形態・週所定労働時間など）。外国籍の人はローマ字氏名・国籍・在留カード番号も入れる。
6. 届書を作りたい行のA列（出力対象）で「○」を選ぶ。
7. 「出力」シートで届種別（社保取得／雇保取得）を選び、［チェック］を押す。
8. 下の一覧に「エラー」が出たら、台帳行と項目名を見て台帳を直し、もう一度［チェック］。「情報」は社保・雇保に未加入の人を除いたという知らせなので直さなくてよい。
9. エラーが0件になったら［CSV出力］を押し、確認画面で「はい」。
   - 社保取得：ツールフォルダの「出力」フォルダに `社保取得_日付_時刻.csv` ができる
   - 雇保取得：「内容確認」シートに転記一覧ができる
10. 社保：届書作成プログラムでCSVを読み込み、個人番号を入力して電子申請する。雇保：転記一覧を見てe-Gov等に入力する。
11. 台帳の「出力済」列に届種別と日時が記録される。もう一度同じ人を出力すると確認画面で知らせる（二重提出に注意）。

## 4. 退職者の届出（退職のたび）

1. 入退職管理マスタの退職DBから対象者の行をコピーし、「退職台帳」のDB貼り付け欄に値で貼り付ける（第3章の1〜4と同じ）。
2. 黄色の追加入力列を埋める。退職DBにないフリガナ・生年月日・性別・被保険者整理番号（入職DBの「保険証番号」）・雇用保険被保険者番号・喪失原因・離職票交付希望など。
3. A列に○を付け、出力シートで「社保喪失」「雇保喪失」を選んで［チェック］→［CSV出力］（第3章の7〜11と同じ）。
4. 退職DBの「社保 資格喪失」「雇保喪失手続」が「対象外」の人は自動で除かれる。
5. 喪失日（退職日の翌日）はツールが自動で計算する。死亡退職のときは喪失原因で「死亡」を選ぶ。

## 5. 届出チェックリストの使い方

1. 「チェックリスト」シートの黄色の欄を上から選ぶ（区分・基準日・生年月日・国籍・社保・雇保など）。
2. 下の表に、必要な届出・提出先・期限日・作成方法が出る。年齢（70歳以上・59歳以上）は生年月日から自動で判定する。
3. 期限日は「安全側（早め）」の日付。例：社保の資格取得届は入職日を1日目として5日以内、雇保の資格喪失届は喪失日の翌日から10日以内。
4. 印刷（A4縦1枚）して、完了日の欄に手書きで記入して使う。
5. 次の人に使うときは、黄色の欄を選び直す。

## 6. エラー・警告が出たとき

| 表示 | 意味 | 直し方 |
| --- | --- | --- |
| 必須項目が空です | 届書に必要な項目が空欄 | 台帳の該当列を埋める（項目名で確認） |
| 日付として読めません | 日付の列に文字が入っている | `2026/11/01` の形で入れ直す |
| コード表に「〇〇」がありません | 選択肢以外の値が入っている | プルダウンから選び直す |
| カンマ・改行は使えません | 値に「,」や改行がある | 取り除く（全角の「，」は可） |
| 機種依存文字があります（警告） | 「髙」「﨑」「①」などがある | 出力はできる。届書作成プログラムでエラーになったら「高」「崎」などに置き換える |
| 台帳に列「〇〇」がありません | マスタの見出しが変わった | マスタの見出し行をコピーし、台帳4行目のDB貼り付け欄に値で貼り直す。直らなければ管理者へ |
| 必須項目が空です（届書コード） | 社保CSVの仕様が未確定 | 管理者に連絡（CSV仕様の確定作業が必要） |
| 異常終了しました | 想定外の問題 | 画面の内容をメモして管理者へ。ログシートにも記録が残る |

## 7. やってはいけないこと

- マイナンバーをツールに入力しない（届書作成プログラム上で入力する）。
- 提出が済んだら、台帳の［台帳をクリア］で個人データを消してから保存する。実データを入れたまま保存しない。
- 出力CSVをツールフォルダの「出力」フォルダ以外に持ち出さない。メールに添付しない。
- 灰色のタブのシート（設定・レイアウト定義・コード表・ルール・ログ）は触らない。直すのは管理者が決めた保守担当者だけ。
- ツールを2人で同時に開いた場合、後から開いた人は読み取り専用になる。保存せずに閉じ、先の人が終わるのを待つ。

## 8. 保守担当者向け：変えたいときはここだけ

| 変えたいこと | 直す場所 | マクロの変更 |
| --- | --- | --- |
| 事業所整理記号・事業所番号・出力先 | 設定シート | 不要 |
| CSVの項目の並び・桁数・固定値 | レイアウト定義 | 不要 |
| コードの値（性別＝1／2など） | コード表 | 不要 |
| チェックリストの届出・期限 | ルール（行を足す・条件を変える） | 不要 |
| マスタの列名が変わった | 台帳4行目の見出し＋レイアウト定義の取得元 | 不要 |
| 雇保をCSV出力に切り替える | 設定シートの届種別一覧「出力形式」＋レイアウト定義 | 不要 |
| CSVの書き方そのもの | マクロ原本（GitHub `tools/届出作成ツール/vba/modExport_utf8.bas`） | 必要（変更履歴シートに記録） |
