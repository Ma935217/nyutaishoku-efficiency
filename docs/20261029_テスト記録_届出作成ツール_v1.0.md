## 2. 試験で見つかり直した不具合

| 不具合 | 原因 | 対応 |
| --- | --- | --- |
| 文字列の切り出しが職員番号にすり替わる | モジュール変数 `mId` が組み込み関数 `Mid` と同名扱い（VBAは大文字小文字を区別しない）。Excelでも起きる | 変数名を `mStaffId` に変更。同種の衝突を点検 |
| LibreOfficeでモジュールが読み込めない | 変数名 `base` が LibreOffice の予約語 | `stem` に変更（Excelには影響なし） |
| 期限日が環境により別の日付に見える | 表示書式 `yyyy/m/d(aaa)` が英語ロケールで誤解釈 | `[$-411]yyyy/m/d(aaa)`（日本語ロケール指定）に変更 |
| 必須エラーの説明が「（）」になる | 備考が空のとき | 備考があるときだけ表示 |
