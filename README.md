# 入退職事務の効率化

社会福祉法人 平成会 人事部「入退職事務の効率化」案件の作業フォルダ（個人情報を含まない文書のみ）。

## 構成
- `docs/` … 効率化案、実務ガイド、Power Automate設定手順書、応募者連絡テンプレート集、辞令テンプレート
- `docs/20261029_計画書_届出スクリプト化◎_v1.0.md` … ヒアリングシートの◎5件をExcelツール化する計画（.docxは写し）
- `docs/20261029_実装手順書_届出スクリプト化◎_v1.0.md` … 実装モデル向けの仕様・テスト・納品手順（.docxは写し）
- `data/` … 入退職届出一覧ヒアリングシート
- `docs/電子媒体届書作成仕様書(健保・厚生年金).pdf`、`docs/届出作成プログラム操作説明書(詳細版）.pdf` … 年金機構の公開資料（仕様の根拠）
- `tools/md_to_docx.py` … docs内のMarkdownを水色基調のWordに変換するスクリプト
- `tools/届出作成ツール/` … 届出作成ツール本体（xlsx）・VBA・生成スクリプト・試験。完成手順は同フォルダの README
- `docs/20261029_運用手順書_届出作成ツール_v1.0.md` … 届出担当者向けの使い方（.docxは写し）
- `docs/20261029_テスト記録_届出作成ツール_v1.0.md` … 試験結果とWindowsで確認する項目
- `docs/20261101_引継ぎ資料_届出作成ツール.md` … 前セッションからの引継ぎ（状態・手順・技術メモ）
- `docs/20261105_監査報告と次工程設計_届出作成ツール.md` … 成果物の監査結果と、次工程（仕様チェック対応→確定→雇保の判断→定着）の設計。Opus 5.5 への実装指示を含む（.docxは写し）

## 届出スクリプト化の進め方
1. 計画書を読み、第6章の確認事項に回答する（済）
2. 実装手順書に従ってツールを作る（済：`tools/届出作成ツール/`）
3. Windows Excelでマクロを取り込んで .xlsm にする（`tools/届出作成ツール/README.md`。v1.1で仕様書第17.0版に対応）
4. 届書作成プログラムの「仕様チェック」で、社保のCSVがエラー0件になることを確認し、「確定」を「済」にする（進め方は `docs/20261105_監査報告と次工程設計_届出作成ツール.md` 第4〜6章）
5. 共有サーバに置き、運用手順書で担当者に説明する
